# Charts

Reusable analytics and performance visualisations.

---

## Included Components

- Handicap Progress
- Score History
- Fairways Hit
- Greens in Regulation
- Putting Statistics
- Strokes Gained
- Distance Trends
- Performance Comparison

---

## Component Requirements

Each chart should include:

• Empty State

• Populated State

• Light mode

• Dark mode

---

## Usage

Charts should make player statistics easy to understand with minimal visual clutter.
