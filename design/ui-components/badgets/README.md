# Badges

Reusable badge components for achievements, status and labels.

---

## Included Components

- Premium
- Verified
- Winner
- New
- Live
- Top 10
- Handicap
- Tournament

---

## Component Requirements

Each badge should include:

• Default

• Active

• Disabled

• Light mode

• Dark mode

---

## Usage

Badges quickly communicate player status and achievements throughout the app.
