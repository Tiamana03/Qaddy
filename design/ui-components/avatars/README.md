# Avatars

Reusable player avatar components used throughout Qaddy.

---

## Included Components

- Small Avatar
- Medium Avatar
- Large Avatar
- Online Status
- Offline Status
- Premium Member
- Guest User
- Team Captain

---

## Component Requirements

Each avatar should include:

• Default state

• Online state

• Offline state

• Premium variation

• Light mode

• Dark mode

---

## Usage

Used anywhere a player profile is displayed including:

- Groups
- Leaderboards
- Live Scoring
- Friends
- Community
- Chat
