# Loaders

Loading indicators used throughout Qaddy.

---

## Included Components

- Spinner
- Progress Bar
- Skeleton Loader
- Course Loading
- Round Loading
- Sync Indicator

---

## Component Requirements

Each loader should include:

• Active

• Complete

• Error

• Light mode

• Dark mode

---

## Usage

Loaders should reassure users that content is being retrieved or processed.
