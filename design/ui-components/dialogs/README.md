# Dialogs

Reusable modal windows and confirmation dialogs.

---

## Included Components

- Confirmation
- Delete
- Success
- Error
- Warning
- Share
- Invite
- Payment

---

## Component Requirements

Each dialog should include:

• Default

• Confirm

• Cancel

• Light mode

• Dark mode

---

## Usage

Dialogs interrupt the current workflow only when user confirmation is required.
