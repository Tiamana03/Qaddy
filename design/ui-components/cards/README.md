# Cards

Reusable card components used throughout Qaddy.

---

## Included Components

- Course Card
- Tournament Card
- Player Card
- Statistic Card
- Weather Card
- News Card
- Round Card
- Achievement Card

---

## Component Requirements

Each card should include:

• Default

• Selected

• Disabled

• Light mode

• Dark mode

---

## Usage

Cards present information in a clean, consistent layout across the application.
