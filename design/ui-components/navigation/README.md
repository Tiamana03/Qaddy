# Navigation

Reusable navigation components used throughout Qaddy.

---

## Included Components

- Bottom Navigation
- Top Navigation
- Side Menu
- Breadcrumb
- Tab Bar
- Navigation Drawer
- Floating Menu
- Back Navigation

---

## Component Requirements

Each navigation component should include:

• Default

• Active

• Selected

• Disabled

• Light mode

• Dark mode

---

## Usage

Navigation should remain familiar and consistent across every feature within Qaddy.
