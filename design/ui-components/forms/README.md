# Forms

Reusable form elements used across Qaddy.

---

## Included Components

- Text Field
- Search Bar
- Dropdown
- Checkbox
- Radio Button
- Toggle Switch
- Date Picker
- Number Input

---

## Component Requirements

Each form component should include:

• Empty

• Focused

• Filled

• Error

• Disabled

• Light mode

• Dark mode

---

## Usage

Forms should provide clear feedback and remain simple to complete.
