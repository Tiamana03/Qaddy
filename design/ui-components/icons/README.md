# Icons

Reusable icon library used throughout Qaddy.

---

## Included Components

- Navigation
- Golf Equipment
- Scoring
- Statistics
- Social
- Weather
- Notifications
- Settings

---

## Component Requirements

Each icon should include:

• Filled

• Outline

• Active

• Disabled

• Light mode

• Dark mode

---

## Usage

Icons should be simple, recognisable and consistent across every screen.
