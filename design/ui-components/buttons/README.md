# Buttons

Reusable button components used throughout Qaddy.

---

## Included Components

- Primary
- Secondary
- Outline
- Text
- Icon
- Floating Action Button
- Segmented Button
- Filter Chip
- Loading Button
- Destructive Button

---

## Component Requirements

Every button should include:

• Default

• Hover

• Pressed

• Disabled

• Light mode

• Dark mode

---

## Usage

Buttons should remain consistent throughout the application and clearly communicate available actions.
