# Qaddy UI Components

This folder contains the reusable building blocks used throughout the Qaddy application.

Unlike screen mockups, these components are designed once and reused everywhere.

## Folder Structure

ui-components/

├── avatars/
├── badges/
├── buttons/
├── cards/
├── charts/
├── dialogs/
├── forms/
├── icons/
├── loaders/
└── navigation/

Each component should include:

• Component mockup
• States (Default, Hover, Pressed, Disabled)
• Light/Dark compatibility
• Usage notes (where applicable)

These components are the single source of truth for UI consistency.
