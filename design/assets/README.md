# Qaddy Design Assets

This folder contains all visual assets used throughout the Qaddy application.

## Asset Categories

### Logos
Primary, secondary, icon and monochrome versions of the Qaddy logo.

### Icons
Custom icon library used throughout the application.

### Colours
Official colour palette including HEX, RGB and usage guidelines.

### Typography
Approved fonts, sizing hierarchy and text styles.

### Illustrations
Custom illustrations and artwork used throughout the app.

### Splash
Launch screen artwork and loading assets.

### App Store
Icons, screenshots and promotional graphics required for App Store and Google Play submissions.

### Marketing
Social media graphics, website assets and promotional material.

Only approved assets should be used in production.
