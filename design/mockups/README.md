# Qaddy Mockups

This folder contains all high-fidelity application screen designs.

Each feature should have its own folder.

Example structure:

mockups/

├── dashboard/

├── golf-bag/

├── round/

├── golf-iq/

├── ask-qaddy/

├── trips/

├── community/

├── profile/

├── statistics/

├── achievements/

├── settings/

└── premium/

Each screen represents the source of truth for development.

Claude Code should always build from these designs before implementing new UI.
