# Tournament Mockups

This folder contains every design related to the Tournament experience in Qaddy.

Included screens:

- Tournament Home
- Tournament Details
- Live Leaderboard
- Player Statistics
- Create Tournament
- Tournament Results
- Prize Payouts

These mockups define the complete tournament user experience, from discovering an event through to viewing final results.

Only approved mockups in this folder should be used as the implementation reference.
