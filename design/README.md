# 🎨 Qaddy Design System

Welcome to the Qaddy design repository.

This folder contains every visual asset used throughout the Qaddy application.

Our goal is simple:

> Build the best-looking golf application in the world.

---

# Design Philosophy

Every screen should feel:

- Premium
- Calm
- Elegant
- Modern
- Simple
- Fast
- Consistent

Every element exists for a reason.

Nothing is added just because it looks cool.

---

# Folder Structure

design/

- Dashboard
- Golf Bag

- Profile

- Premium

---

## branding/

Contains brand assets.

Examples:

- Logos
- Colour palettes
- Typography
- Icons
- Marketing graphics

---

## assets/

Contains supporting artwork used during development.

Examples:

- Hero images
- Backgrounds
- Illustrations
- Placeholder graphics

---

# Design Rules

Every screen should follow the Qaddy Design Bible.

Every component should match the UI Component Library.

Every new design should improve the user experience while remaining visually consistent.
