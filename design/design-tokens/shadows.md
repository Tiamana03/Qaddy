# Qaddy Design Tokens

# Shadows

## Purpose

Elevation helps communicate hierarchy and interaction.

Qaddy uses subtle shadows to maintain a premium appearance.

---

## Shadow Levels

| Token | Usage |
|--------|-------|
| None | Flat surfaces |
| Small | Buttons |
| Medium | Cards |
| Large | Dialogs |
| Extra Large | Floating elements |

---

## Rules

- Avoid heavy shadows.
- Use soft elevation.
- Keep shadows consistent across the app.
