# Qaddy Design Tokens

# Spacing

## Purpose

Spacing tokens provide a consistent layout rhythm throughout the application.

Spacing should never be hardcoded inside widgets. Always reference the spacing tokens.

---

## Base Scale

| Token | Value | Usage |
|-------|------:|-------|
| XS | 4 | Tiny spacing, icon padding |
| SM | 8 | Small gaps |
| MD | 12 | Compact layouts |
| LG | 16 | Standard spacing |
| XL | 24 | Sections |
| XXL | 32 | Large sections |
| XXXL | 40 | Major separation |
| Display | 48 | Hero layouts |
| Hero | 64 | Landing screens |

---

## Usage

- Page padding: XL (24)
- Card padding: LG (16)
- Button padding: MD (12)
- Between sections: XXL (32)
- Between cards: LG (16)

---

## Rules

- Never use arbitrary spacing values.
- Always use the spacing scale.
- Keep spacing consistent across all screens.
