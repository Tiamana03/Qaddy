# Elevation

## Purpose

Elevation defines how surfaces are layered throughout the application.

Elevation should be subtle and consistent.

---

## Levels

| Level | Usage |
|-------|-------|
| 0 | Background |
| 1 | Cards |
| 2 | Navigation |
| 3 | Floating Action Button |
| 4 | Dialog |
| 5 | Modal |

---

## Rules

- Keep elevation minimal.
- Do not stack multiple shadow effects.
- Elevated components should remain visually lightweight.
