# Qaddy Design Tokens

## Purpose

Design Tokens define the visual foundation of the Qaddy design system.

They are the single source of truth for all reusable visual values used throughout the application.

These tokens ensure consistency between mockups, Flutter implementation, and future design updates.

---

## Token Categories

- Colours
- Typography
- Spacing
- Border Radius
- Shadows
- Animations

---

## Rules

- Never hardcode colours inside widgets.
- Never hardcode spacing values.
- Never hardcode border radius.
- Always reference the design tokens.
- All future design changes begin here.
