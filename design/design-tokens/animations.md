# Qaddy Design Tokens

# Animations

## Purpose

Animations should feel smooth, fast and unobtrusive.

The interface should feel responsive without slowing the user down.

---

## Timing

| Animation | Duration |
|-----------|----------|
| Instant | 100 ms |
| Fast | 150 ms |
| Normal | 250 ms |
| Slow | 400 ms |
| Page Transition | 300 ms |

---

## Standard Animations

- Button Press
- Fade In
- Fade Out
- Scale
- Slide Up
- Slide Down
- Page Transition
- Bottom Sheet
- Dialog
- Loading Spinner

---

## Rules

Animations should support the experience, not distract from it.
