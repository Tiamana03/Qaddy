# Release Candidate Revision (October 2026)

**This section supersedes the Melbourne Golf Weekend data above wherever the two differ.** The Trips feature was completed for the Release Candidate (see `docs/features/trips-release-candidate.md`): trips are now stored in an in-memory Riverpod store, every trip has its own pages, and Create Trip, Edit Trip, Chat, Courses, Flights, Accommodation, Transport, Expenses and Planning all read and write real state. That needed richer seed data than the original tables describe, so the values below are the complete, authoritative placeholder set. All names, places, numbers and references are fictional; every website uses the reserved `.example` domain and every phone number is a made-up local number.

Source of truth in code: `lib/features/trips/models/placeholder_trips.dart`.
