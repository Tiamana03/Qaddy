# Purpose

This document defines the placeholder data used throughout Qaddy during development.

Until Supabase and live data are implemented, every screen must use the values defined here.

This ensures:

- consistent demonstrations
- realistic screenshots
- repeatable testing
- consistent UI development

No developer or AI may invent alternative placeholder values unless this document is updated.

# Placeholder Images

Until official assets are created:

- Use user initials instead of profile photos.
- Use Material Icons.
- Use coloured placeholders for course images.
- Do not download or use third-party images.

---

# Development Rules

All placeholder data must:

- remain consistent across every screen
- not conflict with other placeholder values
- represent realistic golf scenarios
- be easy to replace with live data in future

No business logic should rely on placeholder data.

---

# Future Replacement

Once Supabase integration begins:

- placeholder values will be removed
- repositories become the source of truth
- UI should require minimal modification

This document then becomes reference material only.
