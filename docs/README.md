# Development Workflow

Every new feature should follow this process.

1. Product decision
2. Design review
3. Engineering implementation
4. Testing
5. Review
6. Approval
7. Release

---

# Repository Philosophy

Qaddy is built with a documentation-first approach.

Clear documentation reduces misunderstandings, improves consistency and enables both humans and AI engineering tools to contribute effectively.

---

# Guiding Principle

Golfers First.

Every decision should improve the golfer's experience.

Everything else is secondary.
