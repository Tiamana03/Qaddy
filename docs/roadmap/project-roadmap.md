# Qaddy Project Roadmap

**Version:** 1.0

**Status:** Active

**Last Updated:** September 2026

# Purpose

This document is the master roadmap for Qaddy.

It provides a high-level overview of every milestone and sprint in the project.

Each sprint has its own implementation document within `docs/sprints/`.

This roadmap should be updated whenever a sprint is completed.

# Development Workflow

Every sprint follows the same process.

1. Create architecture documents.

2. Create placeholder data.

3. Create sprint document.

4. Run Pre-Implementation Review.

5. Resolve blockers.

6. Implement sprint.

7. Verify.

8. Commit.

9. Push.

10. Update this roadmap.
