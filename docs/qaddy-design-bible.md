# Qaddy Design Bible
Version: 1.0
Status: Active
Last Updated: September 2026

---

# Purpose

This document defines the visual language, user experience principles and design standards of Qaddy.

Every screen, animation, interaction and component within Qaddy must follow this document.

Whenever there is uncertainty, this document takes precedence over personal opinion.

---

# The Qaddy Vision

Qaddy is more than a golf app.

It is the operating system for a golfer's life.

Every round.
Every trip.
Every achievement.
Every friendship.
Every memory.

One place.

The goal is not simply to record golf.

The goal is to make golfers excited to open Qaddy every single day.

---

# Brand Values

Qaddy should feel:

• Premium
• Calm
• Confident
• Inspiring
• Intelligent
• Modern
• Personal
• Trustworthy

Never feel:

• Cheap
• Cluttered
• Corporate
• Generic
• Overwhelming

---

# Design Philosophy

Every screen should answer one question:

"Would this make a golfer smile?"

Design should disappear.

Users should never need instructions.

Navigation should feel obvious.

Every interaction should feel polished.

Small details matter.

---

# Inspiration

The benchmark for Qaddy is not another golf app.

We aim for the craftsmanship of:

• Apple
• Linear
• Airbnb
• Spotify
• Notion

combined with the emotional storytelling of golf.

# Visual Identity

Deep Fairway Green

Accent Colour

Championship Gold

Background

Dark premium green

Cards

Layered elevated surfaces

Text

Success

Natural green

Errors

Muted red

Warnings

Amber

---

# Typography

Headings

Elegant.
Confident.
Easy to read.

Body

Clean.
Comfortable.
Readable.

Never use decorative fonts inside the application.

---

# Spacing

Every screen should breathe.

Use generous padding.

Avoid crowded layouts.

Cards should have consistent spacing.

Buttons should never touch screen edges.

---

# Components

Buttons

Cards

Statistics Panels

Charts

Lists

Achievement Cards

Trip Cards

Round Cards

Profile Cards

Navigation

Every component should have one consistent design language throughout the app.

---

# Imagery

Photography should focus on:

Sunrise golf

Beautiful fairways

Friends

Family

Travel

Achievement

Celebration

Never use stock imagery that feels fake.

Authenticity wins.

---

# Animations

Animations should feel:

Fast

Smooth

Intentional

Never flashy.

Motion should reinforce user actions.

---

# Accessibility

Support scalable text.

Maintain strong colour contrast.

Buttons should always have comfortable touch targets.

Never rely solely on colour to communicate information.

---

# Premium Experience

Premium should feel earned.

Gold highlights.

Extra polish.

Richer visual hierarchy.

Exclusive—not flashy.

---

# Every Screen Must

Reward the golfer.

Tell a story.

Be useful.

Feel premium.

Encourage another round.

---

# Final Principle

People won't remember every score.

They'll remember how Qaddy made them feel.

Every design decision should help create better golfing memories.

Because Qaddy is...

More Than A Game.
