# ADR-001

## Title

Project Foundation

---

## Status

Accepted

---

## Decision

Qaddy will follow a feature-first Flutter architecture using:

- Flutter
- Riverpod
- GoRouter
- Supabase
- Design Tokens
- Theme Extensions

All reusable UI components will be created before feature implementation.

---

## Reason

Maintainability

Scalability

Consistency

Reusable UI

Clean architecture

---

## Consequences

Slightly slower initial development.

Much faster long-term development.

Simpler maintenance.

Higher code quality.
